# sales-dashboard-powerbi
Interactive sales dashboard created using Power BI
## Objective
Designed an interactive dashboard to analyze sales performance.

## Tools Used
- Power BI
- Sample Superstore Dataset

## KPIs Included
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Visualizations Used
- Line chart (Sales trend over time)
- Bar chart (Sales by category)
- Column chart (Profit by region)
- Pie chart (Sales by segment)
- Slicers (Region filter)

## Insights
- Technology category has highest sales
- West region contributes major profit
- Sales show increasing trend over time
